CAR IMAGES

The new Car Mechanic interface uses real car photo references loaded from Wikimedia Commons.
The game does not require a manually-created images/cars folder: photo URLs are defined in game_v07_final.js.
If a remote photo is unavailable, the existing visual fallback is shown.
