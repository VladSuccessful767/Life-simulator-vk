# Путь мастера — v05

Новый игровой прототип:
- 2D-стиль старых VK-игр, без внешних картинок;
- полноценный экран СТО;
- отдельные действия диагностики с расходом энергии;
- согласование цены с клиентом;
- наценка/скидка и шанс отказа;
- нормо-часы и коэффициенты для R4/V6/V8/V12;
- выбор запчастей: оригинал, аналог, восстановленная, б/у;
- база знаний по системам автомобиля и типам двигателей;
- развитие СТО;
- магазин/премиум-валюта как подготовка к будущему VK-платежу;
- сохранение прогресса через localStorage.

Важно: реальные платежи пока не подключены. Перед релизом VK их нужно проводить через серверную проверку платежей.
