# Жизнь: Новый старт — прототип VK Mini App

Это готовый браузерный прототип игры в стиле социальной RPG/симулятора жизни.

## Уже есть
- деньги, энергия, здоровье, репутация;
- уровни и XP;
- работа, учёба, отдых и спорт;
- случайные события;
- история действий;
- сохранение прогресса в браузере;
- магазин внутренних привилегий;
- VIP, автомобиль, квартира и бизнес;
- мобильная адаптация.

## Важно про монетизацию
В текущем прототипе покупки НАМЕРЕННО виртуальные: кнопка покупки сразу выдаёт предмет. Перед публикацией в VK её нужно заменить на реальный платёжный flow VK и серверную проверку платежа. Нельзя считать клиентский JavaScript доказательством оплаты.

## Как развивать до коммерческой версии
1. Разместить frontend на HTTPS-хостинге.
2. Создать приложение VK Mini Apps и указать URL приложения.
3. Добавить VK Bridge для авторизации/профиля/хранилища.
4. Сделать backend (например Node.js) с аккаунтом игрока, балансом и инвентарём.
5. Подключить официальный механизм платежей VK и проверять операции на сервере.
6. Добавить рекламу, ежедневные награды, достижения, рейтинги друзей и кланы.
7. Хранить все покупки и валюту на сервере, а не в localStorage.

## Идея монетизации
Основная валюта игры — ₽ внутри игрового мира, а платные привилегии дают ускорение, косметику и дополнительные возможности. Лучше не продавать прямую победу: игрок должен иметь возможность прогрессировать бесплатно.

## Запуск локально
Открой index.html через локальный HTTP-сервер. Например:
python -m http.server 8080
Затем открой http://localhost:8080
