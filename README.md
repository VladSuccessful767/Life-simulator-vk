# Автомастерская V16

V16 обновляет центр диагностики: методы теперь выбираются прямо кликом по карточкам, без отдельных кнопок выбора внизу.

## Что изменилось
- Новый двухколоночный центр диагностики в стиле современного тёмного автосервиса.
- 8 кликабельных методов: визуальный осмотр, OBD-диагностика, подъёмник, проверка люфтов, проверка тормозов, измерения, компрессия, тест-драйв.
- Справа появляется подробная информация о выбранном методе.
- Кнопка «Начать диагностику» находится только в информационной панели выбранного метода.
- Выбранный метод подсвечивается.
- Выполненные проверки получают отметку ✓.
- Результаты и подтверждение основной неисправности сохраняются.
- Скрытые неисправности по-прежнему обнаруживаются только подходящими проверками и требуют отдельного согласования клиента.
- Существующие реалистичные изображения автомобилей и оборудования сохранены.
- `PREVIEW_V16_DIAGNOSTICS.png` — референс нового дизайна.

## Запуск
Откройте `index.html` в браузере или используйте Live Server.

## Полная замена
Заменить `index.html`, `style.css`, `game.js` и папку `images` из архива. Не создавать вложенную `images/images`.
