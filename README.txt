АВТОСЕРВИС — SIMULATOR FINAL v1.0

Файлы:
- index.html — готовая страница игры
- game_v07_final.js — вся логика игры
- style.css — интерфейс и анимации

Установка:
1. Загрузите все 3 файла в корень GitHub Pages.
2. Откройте index.html через GitHub Pages.
3. Старое сохранение localStorage сохраняется по ключу auto_service_v04.

Основные системы:
- заказы клиентов и многоэтапная диагностика;
- анализ неисправности и ремонт;
- база знаний и тесты/допуски;
- инструменты и ресурс оборудования;
- ремонт инструмента;
- восстановление старых деталей и склад;
- аукцион автомобилей;
- собственные автомобили;
- ремонт, продажа и тюнинг собственных автомобилей;
- развитие СТО до 10 уровня;
- команда из 5 сотрудников и вакансии;
- дневной оборот и зарплаты;
- достижения и финальная цель «Мастерская мечты»;
- мобильная нижняя навигация;
- анимация ремонта тормозов;
- адаптация длинных модальных окон под Android.

Важно: реальная монетизация/платежи в веб-версии не подключены.
